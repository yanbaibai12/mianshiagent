# 商业化方案

## 产品定位

面试简历 Agent 的核心卖点不是“帮用户写一份简历”，而是“围绕简历形成可训练、可复盘、可交付的求职准备系统”。

目标用户分三类：

1. C 端求职者：应届生、实习生、初级社招。
2. B 端机构：高校就业中心、求职培训机构、留学/职业规划机构。
3. 企业内训/招聘团队：用于候选人准备、员工转岗、内部人才盘点。

## 商业化判断

先卖“结果”，不要先卖“AI 工具”。用户真正愿意付费的节点通常不是上传简历，而是：

1. 投递前：用户需要一份能针对 JD 改写的简历。
2. 面试前：用户需要围绕自己项目经历做高压追问训练。
3. 复盘后：用户看到薄弱点，希望拿到可直接背诵和复练的答案。
4. 机构交付时：老师或顾问需要批量管理学生进度和报告。

MVP 的收费闭环建议：

1. 免费用户可以完整体验一次“简历解析 -> JD 适配 -> 模拟面试 -> 简版报告”。
2. 完整报告、报告导出、多 JD 适配、多简历版本放在付费权益里。
3. 早期不强依赖在线支付，可先用 `PAYMENT_PROVIDER=manual` + 人工开通，先验证转化。
4. 每一次高成本 LLM 调用都要记录功能类型、用户、模型、耗时和估算成本，后续再接订单和用量扣减。

## 赚钱路径

### 1. C 端订阅：先验证转化

适合快速上线验证。

- 免费版：1 份简历解析、少量面试题、本地基础报告。
- Pro 月卡：多份简历、JD 定向优化、完整模拟面试、报告导出。
- 单次权益包：按“简历优化次数 / 面试报告次数 / JD 匹配次数”售卖。

建议价格：

- 9.9-19.9 元：单次简历优化 + 1 次模拟面试。
- 29-49 元/月：个人 Pro。
- 99-199 元：求职冲刺包，包含多 JD 改写、多轮面试和报告。

推荐付费墙：

| 权益 | 免费版 | Pro 月卡 | 冲刺包 |
|---|---:|---:|---:|
| 简历数量 | 1 份 | 10 份 | 20 份 |
| 简历模板优化 | 1 次 | 30 次/月 | 100 次/包 |
| JD 定向完善 | 1 次 | 30 次/月 | 100 次/包 |
| 模拟面试 | 1 场 | 20 场/月 | 60 场/包 |
| 完整报告 | 简版 | 完整 | 完整 + 复练建议 |
| Markdown 导出 | 否 | 是 | 是 |
| PDF 导出 | 否 | 是 | 是 |
| RAG 岗位知识增强 | 基础 | 完整 | 完整 |

建议上线价格：

- 免费版：用于获客和验证简历上传转化。
- Pro 月卡：39 元/月，首月 19.9 元。
- 求职冲刺包：129 元/30 天，突出“投递前简历 + 面试前复盘”。

当前代码已预留的发布变量：

| 变量 | 建议值 | 用途 |
|---|---:|---|
| `FREE_RESUME_QUOTA` | 1 | 免费简历数量 |
| `FREE_INTERVIEW_QUOTA` | 1 | 免费面试数量 |
| `FREE_OPTIMIZE_QUOTA` | 1 | 免费模板优化次数 |
| `FREE_JD_ADAPT_QUOTA` | 1 | 免费 JD 适配次数 |
| `FREE_REPORT_EXPORT_QUOTA` | 0 | 免费报告导出次数 |
| `PRO_MONTHLY_PRICE_CNY` | 39 | Pro 月卡价格 |
| `PRO_RESUME_QUOTA` | 10 | Pro 简历数量 |
| `PRO_INTERVIEW_QUOTA` | 20 | Pro 面试数量 |
| `SPRINT_PACKAGE_PRICE_CNY` | 129 | 求职冲刺包价格 |

当前代码已落地的最小商业闭环：

1. `GET /api/business/entitlements`：登录用户查看当前套餐、用量、剩余额度和升级入口。
2. `POST /api/business/upgrade-request`：记录升级意向，适合早期人工跟进转化。
3. `billing_accounts`：保存用户当前套餐、状态、来源和到期时间。
4. `usage_records`：记录模板优化、JD 适配、报告导出等高价值功能调用。
5. `BILLING_ENABLED=true` 时，超出套餐额度会返回 402，前端同步禁用对应按钮。

建议的前端付费提示触发点：

| 触发点 | 文案方向 | 转化目标 |
|---|---|---|
| 免费 JD 适配用完 | “解锁更多岗位定向改写” | Pro 月卡 |
| 完成 3 道题后生成报告 | “查看完整薄弱点和复练答案” | 单次报告 / Pro |
| 点击 Markdown/PDF 导出 | “导出可交付版本” | Pro |
| 多份简历版本管理 | “为不同岗位保留独立版本” | Pro |
| RAG 知识库定制 | “按岗位方向接入专项题库” | B 端线索 |

### 2. B 端机构版：做稳定现金流

更容易形成稳定收入。

- 账号池：机构批量分配学生账号。
- 班级/批次管理：按学校、专业、岗位方向分组。
- 使用报表：学生使用次数、简历完成度、面试薄弱点分布。
- 模板定制：机构自有简历模板、话术风格、岗位题库。

收费方式：

- 按账号年费：30-100 元/人/年。
- 按机构套餐：1-10 万元/年，取决于账号量、模板定制、私有化需求。
- 私有化部署：一次性实施费 + 年维护费。

B 端套餐建议：

| 套餐 | 目标客户 | 年费建议 | 核心权益 |
|---|---|---:|---|
| Starter | 小型求职社群/工作室 | 9,800 元/年 | 200 账号、基础模板、使用统计 |
| Growth | 高校院系/培训机构 | 38,000 元/年 | 1,000 账号、班级管理、模板定制、数据看板 |
| Enterprise | 大型机构/私有化 | 98,000 元+/年 | 租户隔离、专属知识库、私有部署、审计日志 |

### 3. 专家服务增值：提高客单价

AI 做基础自动化，人做高客单价服务。

- 简历人工精修。
- 模拟面试陪练。
- Offer 冲刺包。
- 垂直岗位专项包：后端、前端、产品、运营、数据分析、算法。

收费方式：

- 99-299 元：人工精修一次。
- 199-599 元：专家模拟面试一次。
- 999+ 元：完整求职辅导包。

服务组合建议：

- AI 简历初筛免费，人工精修付费。
- AI 模拟面试报告免费预览，专家复盘付费。
- 岗位专项包按方向售卖：后端、前端、产品、运营、数据分析。

### 4. RAG 知识库变现：做差异化

RAG 不只是提升问答准确度，也可以成为可售卖资产。

- C 端：按岗位方向开放专项知识包，例如后端、产品、数据分析、算法、运营。
- B 端：给机构配置专属题库、专属评分 rubrics、专属模板风格。
- 企业版：私有知识库隔离，支持企业内部岗位标准和晋升题库。

建议先做 5 个高频方向，每个方向维护：

1. 岗位能力模型。
2. 简历表达规则。
3. 高频面试题和追问链。
4. 评分标准。
5. 优秀答案结构。

## 成本与毛利模型

核心成本：

1. LLM token 成本。
2. 文件存储和数据库成本。
3. 支付通道手续费。
4. 专家服务人力成本。

上线前必须记录：

- 每次简历解析成本。
- 每次模板优化成本。
- 每次 JD 适配成本。
- 每场面试出题成本。
- 每次评分成本。
- 每份报告成本。

建议目标：

- C 端 AI 自动化功能毛利率不低于 70%。
- B 端 SaaS 毛利率不低于 80%。
- 专家服务按人力交付，毛利率不低于 40%。

单次链路毛利估算公式：

```text
单次毛利 = 用户支付金额 - LLM 成本 - 文件/数据库成本 - 支付手续费 - 人工服务成本
```

建议上线前建立最低成本表：

| 功能 | 必记字段 | 用途 |
|---|---|---|
| 简历解析 | 输入长度、模型、耗时、是否兜底 | 估算免费体验成本 |
| 模板优化 | 模板、模型、输出长度 | 评估 Pro 使用频率 |
| JD 适配 | JD 长度、匹配分、输出长度 | 识别高转化岗位 |
| 面试评分 | 题目数、回答长度、模型成本 | 控制冲刺包成本 |
| 报告导出 | 报告长度、导出次数 | 设计付费墙 |

## 发布首版商业闭环

首版不要一开始做复杂支付系统，可以先这样发布：

1. 免费注册，允许完成一条完整链路。
2. 超过免费额度后展示“升级 Pro”入口。
3. 早期可先用人工收款/兑换码开通权益。
4. 后续再接微信/支付宝/Stripe 订单表和支付回调。

最小计费数据模型：

- `plans`：套餐定义。
- `subscriptions`：用户订阅状态。
- `usage_records`：每次 AI 功能使用记录。
- `quota_balances`：剩余额度。
- `orders`：支付订单和回调状态。

最小收费版本的后端策略：

1. `BILLING_ENABLED=false`：只展示升级入口，不做强扣减，用于演示和获客。
2. `BILLING_ENABLED=true` + `PAYMENT_PROVIDER=manual`：人工收款后给用户开通额度，适合最早期。
3. `BILLING_ENABLED=true` + 第三方支付：订单创建、回调验签、订阅/额度自动发放。
4. 企业客户优先用合同 + 后台开通，不必被 C 端支付链路阻塞。

## 90 天赚钱路线

| 时间 | 目标 | 交付 |
|---|---|---|
| 第 1-2 周 | 验证用户愿意完成主链路 | 免费体验、升级入口、人工开通 |
| 第 3-4 周 | 验证付费点 | Pro 月卡、报告导出、JD 适配额度 |
| 第 5-8 周 | 降低成本和提升转化 | 成本统计、Prompt 回归、套餐 A/B |
| 第 9-12 周 | 打 B 端样板 | 机构账号池、班级报表、专属知识库报价 |

优先级建议：

1. 先卖 39 元/月 Pro 和 129 元冲刺包。
2. 同时找 3-5 个求职社群或就业老师做机构试点。
3. 不要过早做复杂会员中心，先把额度、导出、报告质量和销售线索跑通。
4. 等有稳定付费，再补自动支付、发票、合同、租户后台。

## 企业化功能路线

### Phase 1：可上线 MVP

- 登录注册、简历上传/解析、模板优化、JD 完善。
- 模拟面试、评分、报告、Markdown 导出。
- 本地模型兜底 + 真实 LLM 接入。
- 基础安全：输入限制、限流、安全头、数据隔离。

### Phase 2：可收费

- 支付与订单。
- 用户权益与用量计费。
- 真实 LLM 成本统计。
- 模板市场与岗位题库。
- 报告 PDF 导出。
- 简历版本管理。

### Phase 3：B 端企业版

- 租户模型。
- 机构后台。
- 批量导入账号。
- 班级/项目管理。
- 数据看板。
- 自定义模板和题库。
- 审计日志。
- 私有化部署包。

## 关键指标

- 简历上传到首次优化完成率。
- JD 适配使用率。
- 单次面试完成题数。
- 报告生成率。
- 7 日留存。
- 免费到付费转化率。
- 单用户模型成本。
- 每份报告毛利。

## 最小可卖版本定义

必须做到：

1. 用户能在 5 分钟内完成一次“简历解析 -> JD 优化 -> 面试题 -> 报告”。
2. 报告能明确指出薄弱点，不只是泛泛鼓励。
3. 输出能导出，用户觉得“可保存、可复盘、可交付”。
4. 成本可控，单用户单次完整链路模型成本可预估。
5. 有明确付费墙：完整报告、更多 JD 适配、多简历版本、PDF 导出。
